🎙 Voice Training

Say a spell. You’ll see what it heard and how much of it each spell owns, judged from what’s been trained so far. If it’s wrong, pick the spell you meant and teach it. ← Back to the game

1 · Say something

Works in Chrome or Edge, in English. Two things listen at once: speech recognition, which turns what you said into English words, and a recording of the sound itself, which is compared with what you already taught. The sound decides when you stopped talking, so the answer comes straight away. “Listen” keeps listening, so you can say several spells in a row. “Upload a recording” does the same with an audio file. The text box tries a phrase without speaking (words only).

3 · Your training data ● unsaved changes

Save in this browser keeps it in localStorage for this whole site (domain): the game on the same site and browser uses it right away, without reloading. Other visitors and other browsers are not affected.
Download gives a file for the source code: the project owner (or anyone with a fork) replaces js/voice-training-data.js with it and commits, so every player benefits. It contains the phrases already in the source plus yours.
Load existing… uses a voice-training-data.js you already have as the starting point instead. Without it, the starting point is the project’s latest js/voice-training-data.js, fetched from GitHub (the dashed chips), so you never start from scratch.
